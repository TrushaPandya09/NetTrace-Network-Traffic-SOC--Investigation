# 🔎 NetTrace — Network Traffic Analysis & SOC Investigation

> **From Packet Analysis to Security Investigation**

NetTrace is a hands-on network traffic analysis and SOC investigation project focused on developing practical skills in **Wireshark, PCAP analysis, network protocols, and security-focused traffic investigation**.

The project follows a two-phase approach: first establishing strong packet-analysis fundamentals, followed by dedicated security investigations involving suspicious network activity, indicators of compromise, and SOC-oriented investigation workflows.

---

## 🎯 Project Objectives

- Develop practical **Wireshark and PCAP analysis** skills.
- Understand and analyze common network protocols and their behavior.
- Investigate network endpoints, conversations, and communication patterns.
- Reconstruct network activity and communication timelines.
- Analyze HTTP, HTTPS/TLS, DNS, TCP, UDP, ARP, DHCP and other protocols.
- Perform security-focused investigations using packet-level evidence.
- Extract relevant **Indicators of Compromise (IOCs)** from network traffic.
- Apply a structured **SOC analyst investigation methodology**.
